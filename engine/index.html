This is a design prototype for a real decomp merge. It runs entirely in your browser — no ROM, no JAR, no assets from either game. It shows what it feels like when OoT's actor/collision/camera system drives a Minecraft voxel world.

What you're seeing

Voxel Hyrule Field (2048 logic, 60×60 demo) with OoT structures as voxel actors: Deku Tree stump, Castle wall, Kakariko houses, ravine + chain targets, pond with Octorok. Fog + Lod are Minecraft; sky color + sun position are OoT's EnvironmentContext.

Technical

Prototype: Three.js + naive voxels. Real: liboot.a (OoT GCC) + JNI Minecraft + shared MergedState. See architecture.md.
